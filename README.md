# Growth Journey PWA

Mobile-friendly daily habit tracker. Habits and checkmarks are saved in this browser on this device.

## Publish free with GitHub Pages
1. Open your GitHub repository `GrowthJourney`.
2. Upload `index.html`, `manifest.json`, and `sw.js` to the repository root (top level).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then Save.
6. Wait for GitHub Pages to show the published URL.
7. Open that URL in Chrome on Android, tap ⋮, then **Add to Home screen** or **Install app**.

This is a PWA website, not an APK. Install/offline support needs the HTTPS GitHub Pages URL, not a local file.
