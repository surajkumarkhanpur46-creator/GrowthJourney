Growth Journey — same black and gold visual style, responsive website with working habit checks, progress, goal list, and device-local saving.

Publish on GitHub Pages:
1. Upload index.html to the root of your repository.
2. Open Settings > Pages.
3. Set Source to Deploy from a branch, Branch main, folder /(root), then Save.
4. Open your Pages website URL in Chrome on Android.
5. Chrome menu (⋮) > Add to Home screen / Install app.

Habit progress and goals save in this browser on this device (localStorage); they are not synced between devices.
